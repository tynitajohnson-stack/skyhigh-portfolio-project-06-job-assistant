# Ticket 0: Role Research

## Target Role: Junior Cloud Engineer (AWS-Focused)

### 1. Research Objective

The goal of this research is to identify the technical skills, qualifications, and experience employers expect from AWS-focused cloud engineers.

This research will guide the development of the SoleCloud Job Application Assistant's job-matching and resume-tailoring features.

### 4. What Makes a Strong Cloud Engineering Resume?

**Resume Likely to Receive a Callback**

A strong junior cloud engineering resume clearly demonstrates practical AWS experience, relevant technical skills, and measurable project accomplishments.

It should include:

- A targeted professional summary.
- Relevant AWS services and technical skills.
- Hands-on cloud infrastructure projects.
- Infrastructure automation experience.
- Relevant certifications and education.
- GitHub repositories demonstrating completed technical projects.
- Specific examples of troubleshooting, monitoring, and security implementation.

A strong project bullet might read:

"Configured an Amazon Linux EC2 instance, installed and enabled Nginx, and created a reusable Amazon Machine Image to support repeatable server provisioning."

This bullet demonstrates concrete technical work without inventing business outcomes.

**Resume More Likely to Be Filtered Out**

A weaker resume may:

- Use the same generic summary for every application.
- List cloud technologies without supporting examples.
- Omit relevant job-description keywords.
- Focus on unrelated responsibilities without connecting transferable skills.
- Lack technical projects or evidence of hands-on experience.
- Contain unsupported claims or exaggerated accomplishments.
- Use unclear formatting that makes qualifications difficult to identify.

Keyword matching alone does not guarantee an interview. Recruiters also evaluate relevant experience, demonstrated ability, and the quality of accomplishments.

### 5. Target Profile for the Tailoring Engine

The SoleCloud Job Application Assistant will optimize application materials for an entry-level or junior AWS-focused Cloud Engineer who has foundational knowledge of cloud infrastructure, Linux, networking, security, and infrastructure automation. The ideal candidate demonstrates hands-on experience through AWS projects involving EC2, S3, VPC, IAM, and monitoring, with developing skills in Terraform, Python, Git, and CI/CD. The tailoring engine will prioritize relevant technical accomplishments, transferable troubleshooting experience, certifications, and practical cloud projects. It will compare job descriptions against verified candidate qualifications, highlight relevant keywords, identify missing skills, and suggest truthful improvements without fabricating employment history, certifications, or technical experience.

### 6. Human-in-the-Loop Requirements

The application will assist users with job discovery, application tailoring, and application tracking.

It will not automatically submit job applications.

Every user must review the generated materials and manually submit applications through the employer's authorized application process.

The project will remain local-first, avoid prohibited scraping, and keep secrets outside version control.

### 7. Research Conclusion

The reviewed job postings demonstrate that AWS cloud engineering roles commonly value cloud infrastructure knowledge, automation, networking, security, troubleshooting, and the ability to maintain reliable systems.

For a junior AWS-focused cloud engineer, a strong portfolio should demonstrate practical technical skills rather than simply listing tools.

This research provides the initial requirements for the job-matching and application-tailoring components of the SoleCloud Job Application Assistant.
